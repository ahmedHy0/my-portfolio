# Phase 03 — Design System, Brand, Color, and Typography

## Objective

Create the visual foundation for a premium Data Engineer portfolio using the provided logo as the source of brand direction.

Read and follow:

- `DATA_ENGINEER_PORTFOLIO_MASTER_PROMPT.md`
- `DATA_ENGINEER_PORTFOLIO_DESIGN_SYSTEM_ADDENDUM.md`

## Required Design Decisions

Define tokens for:

- Backgrounds.
- Surfaces.
- Text hierarchy.
- Brand accent.
- Data-flow accent.
- Healthy state.
- Warning state.
- Error state.
- Architecture/intelligence accent.
- Borders.
- Shadows.
- Spacing.
- Typography.
- Motion durations and easing.
- Breakpoints.

Use the logo to harmonize the exact accent colors. Do not use a random palette unrelated to the logo.

## Recommended Direction

Start from:

- Deep graphite/midnight backgrounds.
- Electric aqua or cyan data flow.
- Mint for healthy/completed states.
- Amber for warnings or pending states.
- Coral only for real error states.
- Violet/indigo for architecture or warehouse layers.

Keep the palette disciplined. Most of the interface should remain dark neutral surfaces and readable text.

## Brand Asset Rules

- Preserve the original logo.
- Do not distort or recolor destructively.
- Create a simplified favicon only if necessary.
- Ensure the logo has strong contrast in header, intro, footer, and browser tab.
- Do not place the logo inside excessive animation.

## Deliverable Before Phase 04

Create and inspect:

- Design token file.
- Typography setup.
- Global background.
- Button styles.
- Card/surface styles.
- Focus states.
- Logo treatment.
- Desktop/mobile breakpoints.

Do not build all sections yet. Confirm the visual foundation is coherent before proceeding.
