# Smartphone Specification Analysis 2025

Data analysis project examining trends in the 2025 smartphone market. Analyzed 930+ devices across multiple brands to compare specifications, pricing, and performance tiers.

---

## 🛠️ Tools & Technologies
- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Jupyter Notebook**

---

## 🔑 Key Features

### 1. Data Cleaning & Preprocessing
* Handling missing values
* Duplicate detection and removal
* Outlier analysis and filtering

### 2. Feature Engineering
* Categorization into RAM-based performance tiers:
  * **Budget**
  * **Mid-Range**
  * **Flagship**

### 3. Statistical Analysis & Data Normalization
* Descriptive statistics across specifications and pricing
* Feature normalization for unbiased comparison

### 4. Data Visualizations
* **Scatter Plots**: Pricing vs. performance relationship
* **Histograms**: Distribution of specifications (RAM, Battery, Display)
* **Trend Analysis**: Market trends across brands and release cycles
